# Licenze e diritti — checklist

La licenza del software non equivale alla licenza dei video, delle musiche o dei modelli.

## Dipendenze e modelli
Prima di aggiungere una dipendenza o un modello:
- registrare nome, versione, URL, licenza, restrizioni commerciali e data di verifica;
- verificare redistribuzione, uso commerciale, attribuzione, watermark e termini del servizio;
- preferire componenti con licenza permissiva e uso locale, se compatibili;
- non integrare API a pagamento come requisito obbligatorio;
- segnalare ogni licenza ambigua prima dell'integrazione.

## Asset multimediali
Per ogni media conservare URL, titolare, data acquisizione, licenza/permesso, crediti richiesti e modalità di riutilizzo. Non inferire il permesso dal fatto che un media sia pubblico o scaricabile. Bloccare la pubblicazione se i diritti necessari non sono documentati. Rispettare termini e restrizioni tecniche dei siti; niente aggiramento DRM.

Questa checklist è una misura operativa, non un parere legale. Ogni caso dubbio deve essere segnalato.
